Privacy & Terms

Gauntlet Legends Remake by kungFuDOOM · Last updated October 19, 2026

What this game is

A free fan-made browser remake. You do not need an account.

Hosting

The game is hosted on GitHub Pages and Vercel. Those hosts see your IP address and basic browser info when you load the page, under their own policies.

Global leaderboard

If you submit a score, we store it in Supabase:

  • the name you choose
  • your score, class, level reached, and whether you won
  • a hashed random ID for this browser, used only to limit spam

Leaderboard names and scores are public. Anyone can see them.

Online play

Online play uses the public PeerJS server at 0.peerjs.com for matchmaking. That server sees your IP address. Players in the same room can also see each other's IP addresses while connected.

On your device

The game uses localStorage for saves and settings. There are no cookies, no analytics and no ads.

Remove your score

Email kungfudoom@mail.grokbot.com with the leaderboard name you want removed.
